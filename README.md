# Behavioral Role Framework

A network science and machine learning framework for discovering behavioral roles in international trade networks.

## Research Objective

This project develops the **Behavioral Role Framework (BRF)** to identify and characterize behavioral roles in international trade networks using network science and machine learning techniques.

The framework analyzes annual bilateral trade networks and combines structural network features, dimensionality reduction, clustering, temporal analysis, and machine learning for behavioral role discovery.

## Methodology

The analysis includes:

- Network construction and structural feature extraction
- Exploratory data analysis
- Principal Component Analysis (PCA)
- Clustering
- Temporal sequence analysis
- Behavioral role assignment
- Framework evaluation
- Random Forest feature importance

## Data

The study uses annual bilateral trade data from **UN Comtrade** and economic indicators from the **World Bank** covering 1992–2024.
